# Моделирование жидкосцинтилляционного детектора

Сферический детектор радиуса $R$, заполненный сцинтиллятором, с $N$ фотоумножителями на внутренней поверхности. Проект постепенно усложняет модель: от геометрии и трассировки фотонов до байесовской реконструкции энергии и положения события. Полные формулировки заданий находятся в [TASKS.md](TASKS.md).

## Задачи и результаты

| № | Ноутбук | Главный результат |
|---|---|---|
| 1 | [Геометрия детектора](task1_detector_geometry.ipynb) | 40 ФЭУ на спирали Фибоначчи, покрытие 2.50% подтверждено Монте-Карло |
| 2 | [Источник света](task2_source.ipynb) | Изотропные направления и линейный выход $\langle n\rangle = YE$ |
| 3 | [Трассировка и сбор заряда](task3_tracing_and_charge.ipynb) | $\langle Q\rangle \approx 125$ ф.э.; формула задания завышает заряд в 4 раза |
| 4 | [Распределения заряда](task4_charge_distributions.ipynb) | $\sigma_Q/\langle Q\rangle \propto 1/\sqrt E$; смещение на 1 м меняет средний заряд меньше чем на 1% |
| 5 | [Генераторы](task5_generators.ipynb) | Пуассоновское число фотонов, генераторы по одному фотону и пачками по 100 |
| 6 | [Затухание света](task6_attenuation.ipynb) | В центре заряд падает в $e^{-R/L} \approx 0.78$ раза, отклик вдоль оси становится неоднородным |
| 7 | [Массивы numpy](task7_numpy_speedup.ipynb) | Событие считается примерно в 80 раз быстрее, чем на чистом Python |
| 8 | [Большой детектор](task8_large_detector.ipynb) | Сетка быстрее перебора более чем в 100 раз, k-d дерево — примерно в 20 раз |
| 9 | [Модель в PyMC](task9_pymc_model.ipynb) | Распределение заряда согласуется с numpy-моделью (KS $p = 0.61$) |
| 10 | [Байесовская реконструкция](task10_reconstruction.ipynb) | $\sigma_E/E \approx 10\%$ и ~11 см по координате при 1.5 МэВ; пуллы согласуются с $\mathcal N(0, 1)$ на сериях при 1.5 и 3 МэВ |

## Структура кода

| Файл | Содержание |
|---|---|
| [detector.py](detector.py) | Класс `Detector`: геометрия, поиск ФЭУ, трассировка, затухание, фотоэлектроны |
| [source.py](source.py) | Класс `Source`: число и направления фотонов, генераторы |
| [simulation.py](simulation.py) | Серии событий и аналитическая доля фотонов на каждом ФЭУ |
| [pure_python.py](pure_python.py) | Эталон на чистом Python для сравнения скорости в задаче 7 |
| [pymc_model.py](pymc_model.py) | Модель детектора в PyMC, пофотонная и мультиномиальная |
| [reconstruction.py](reconstruction.py) | Правдоподобие Неймана типа A, MAP-старт и NUTS |
| `test_*.py` | Тесты всех модулей |
| [test_physics.py](test_physics.py) | Независимая проверка физики: ожидания считаются заново, допуски заданы заранее |
| [check_calibration.py](check_calibration.py) | Большая статистика и серии реконструкций, на которые ссылаются выводы задач 3, 4 и 10 (около полутора часов) |
| [check_mutations.py](check_mutations.py) | Проверка самих тестов: заведомые ошибки в модели должны быть пойманы |

## Допущения

- Катод — плоский диск, вписанный в сферу: его край лежит на поверхности.
- Число фотонов равно ровно $YE$ в задачах 2–4 и в сравнении задачи 9 с задачей 4. С задачи 5 оно пуассоновское, как требует условие.
- Параметр $a$ — среднее число фотоэлектронов на фотон, как в задаче 3. При $a = 0.5$ вероятность выбить хотя бы один фотоэлектрон равна $1 - e^{-a} \approx 0.39$, а не $a$, как сказано в общей постановке.
- Ожидаемый заряд равен $aYE\,Nr^2/4R^2$. В формуле из задачи 3 нет четвёрки, поэтому её значение в 4 раза больше результата моделирования.
- Приближение малого диска в правдоподобии задачи 10 грубеет к стенке: при 1.7 м под катодом до 8.5% на канал. Смещения реконструкции это не даёт, но фидуциальный объём ограничен радиусом 1.7 м.
- У `Detector` и `Source` должны быть разные seed: с одинаковым seed у них один поток случайных чисел.

## Запуск

Проект проверен на Python 3.14.

```bash
python -m venv venv_dev
```

```bash
venv_dev/Scripts/pip install -r requirements.txt
```

```bash
venv_dev/Scripts/python -m pytest -q
```

Калибровка реконструкции и проверка тестов заведомыми ошибками занимают несколько минут и запускаются отдельно:

```bash
venv_dev/Scripts/python -m pytest -q -m slow
```

```bash
venv_dev/Scripts/python check_mutations.py
```

```bash
venv_dev/Scripts/jupyter lab
```

Виджеты k3d появляются после запуска ячеек (Run All). На GitHub их не видно, поэтому в задачах 1 и 8 ту же геометрию показывают статичные рисунки.
